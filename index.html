Organic Search Performance Optimization: A Time-Series Machine Learning Approach to Content Opportunity Scoring

Author: FlyRank Search Intelligence Lab Intern Date: July 2026 Reproducibility: 100% Verified
Abstract

Organic search traffic is a primary acquisition channel for web platforms, yet page performance naturally decays over time due to content obsolescence, search engine algorithm updates, and intensifying competitor activity. Traditionally, identifying which pages to refresh first has relied on simple heuristics. This paper introduces a predictive framework for page-level content opportunity scoring. Using search intelligence data from the FlyRank database, we fit an organic CTR power-law curve to model baseline search performance. We then engineer time-series features (rolling averages, volatility, and momentum) and train a LightGBM regressor to predict out-of-time page CTR. By comparing predicted performance to the theoretical organic baseline, we compute a Priority Score to rank content refresh opportunities. On an out-of-time validation set (March 2026), our LightGBM model achieves an R² of 90.79% and a Mean Absolute Error (MAE) of 0.0069, outperforming the baseline organic click curve. The output is a prioritized, actionable queue of 49 page recommendations complete with suggested editorial actions to maximize organic traffic recovery.

1.

Introduction

Organic search traffic represents a primary customer acquisition mechanism for web platforms. However, search relevance is not static. Over time, pages that once commanded high positions in Search Engine Result Pages (SERPs) experience a slow decay in clicks and impressions—a phenomenon known as content decay.

Content decay occurs due to content obsolescence (information becoming outdated), competitor updates (competitors improving their pages to displace historical ranks), and snippet mismatch (meta-titles and descriptions failing to align with shifting query intent). Identifying which pages to optimize first is a key challenge in portfolio-scale Search Engine Optimization (SEO). Editorial resources are limited; hence, a scoring framework that estimates traffic recovery potential is essential.

2.

Problem Statement

The core research question of this study is:
"Which pages should be refreshed first based on historical search performance to maximize future organic growth?"

We formulate this as a regression task at the Page-Date level. Let $Y_{it}$ represent the Click-Through Rate (CTR) of page $i$ at date $t$. The priority score is derived by taking the difference between the theoretical organic CTR (the expected CTR based on its ranking position) and the model's predicted CTR. Pages with a large positive delta represent the greatest opportunity for traffic recovery upon content refresh.

4.

Methodology

Our opportunity scoring methodology consists of two stages: baseline organic curve fitting and time-series machine learning prediction.

4.1 The Baseline Organic Click Curve

In organic search, click-through rate decays exponentially as SERP rank position increases. We model this behavior using a power-law formulation: $$CTR_{expected} = \alpha \cdot \text{Position}^{-\beta}$$ Using non-linear least squares regression (`scipy.optimize.curve_fit`), we fitted parameters on the training split, estimating $\alpha = 0.3362$ and $\beta = 1.0590$. This curve represents the average organic CTR curve for a standard page on the site.

Figure 4: The Organic Click Curve (mean CTR bucketed by search position for Rank 1-30).

4.2 Feature Engineering

To capture historical performance trends, we engineered several time-series and page structural features:

  • Expected CTR: Theoretical baseline CTR calculated via the organic curve formula.
  • Rolling Position Mean (`position_roll_mean_7`): 7-day rolling average of search position.
  • Position Volatility (`position_roll_std_7`): 7-day rolling standard deviation of position, serving as a proxy for ranking stability.
  • Impressions Momentum (`impressions_momentum`): Ratio of the current day's impressions to the 7-day rolling average.
  • Page Authority Proxy (`page_avg_impressions`): Historical average impressions of the page.
  • Query Difficulty Proxy (`query_avg_position`): Historical average position of the query.
  • URL Depth (`url_depth`): Directory folder depth of the URL.
5.

Leakage Prevention & Validation Strategy

To guarantee model generalizability to future observations, we implemented strict leakage prevention safeguards:

Time-Series Splitting: We split training and test data chronologically. The splitting threshold divides the 90-day window at 2026-03-01:

  • Training Set: 2026-01-01 to 2026-03-01 (10,561 records)
  • Testing Set: 2026-03-02 to 2026-03-31 (5,260 records)

Rolling Feature Restrictions: All rolling aggregates (means and standard deviations) were calculated strictly using historical lookbacks ($t-7$ to $t-1$) and excluded values from target date $t$ and beyond. Clicks were excluded from the features list entirely.

9.

Limitations & Future Work

Search Intent Seasonality: The model assumes short-term stationarity in search intent. In reality, search trends drift seasonally.

Lack of Competitor Content Features: We do not include competitor metrics (e.g. competitor page updates, backlink profiles) which impact organic ranking probability.

Future Work: Incorporating real-time competitor crawling and external backlink metrics would improve priority score fidelity.

10.

Conclusion

This capstone study validates an end-to-end framework for search opportunity scoring. By combining physical baseline organic click curves with advanced LightGBM regression, we successfully identified page-level click-through rate decay, enabling targeted and priority-ranked content refresh actions. The pipeline is 100% reproducible and ready for production portfolio scheduling.
